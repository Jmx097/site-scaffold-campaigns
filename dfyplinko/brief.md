## Who this page is for (ICP)

**Job titles (primary):**
- Founder / Owner / Managing Partner of an MSP that's already committed — they know they're not building this internally
- Head of Operations at a larger MSP where the owner has delegated ops automation
- Sometimes: VP of Sales where the MSP has a dedicated sales org but outbound isn't working

**Company profile:**
- 10 – 100 employee MSPs (broader than tryplinko because the committed tier can handle larger accounts)
- North American, English-speaking
- $1M – $25M annual revenue
- Already spending on sales (they've tried a BDR, an agency, or a tool stack and it hasn't worked)
- Increasingly: MSPs who want AI-native internal ops (ticket triage, client onboarding docs, proposal generation) but don't have the time to become the specialist

**Buying trigger:**
- Tried tryplinko-tier or equivalent and are ready to commit to the full engine
- Spending $8-15k/month on sales tooling + underperforming BDR with nothing to show
- Heard about Claude Cowork / OpenClaw from peers or AI-search and want it set up — not to DIY it
- Have seen ChatGPT demos but want running systems, not prompts
- Internal ops is eating time they should spend on sales or delivery

**AI-search intent buyer (a subset):**
- Searched "AI automation agency for MSPs" or "Claude Cowork for MSPs" in an AI chat tool
- Perplexity/ChatGPT surfaced this page in a result
- Lands warm, knows what Claude Cowork is, skeptical of "yet another AI consultancy"

**Emotional state when they land:**
- More qualified than tryplinko traffic. These buyers are further along.
- Still MSP-allergic to fluff — "AI-powered everything" still makes them bounce.
- Wants proof of running systems, not slide decks.
- Values stack transparency. Naming OpenClaw, Claude Cowork, n8n in prose builds trust here the same way naming Apollo/HeyReach does on tryplinko.

## AI-search optimization (unique to this page)

This is the strategic pivot — dfyplinko is the only page that's also written to rank in AI search. Rules:

### Entity density
- Target primary entities appear 5-8 times each in visible prose: OpenClaw, Claude Cowork, MSP, AI automation
- Target secondary entities appear 3-5 times: outbound engine, n8n, Apollo, HeyReach, Smartlead, done-for-you / DFY
- Natural, not stuffed. If a paragraph reads like keyword spam, it ranks worse, not better.

### Structure for AI crawlers
- `<h1>` contains OpenClaw OR Claude Cowork OR both
- `<h2>` subheadings use natural-language queries where possible ("What does the 90-day DFY engine include?")
- FAQ section uses `<h3>` question + `<p>` answer, flat structure
- Schema.org markup: `FAQPage`, `Service`, `Organization`
- Meta description mentions OpenClaw, Claude Cowork, MSP, done-for-you

### Question-format headings in FAQ
AI search crawlers weight Q&A format because it matches how users type queries. Target questions for the FAQ:
- "What is Claude Cowork for MSPs?"
- "How does OpenClaw help an MSP?"
- "What does a done-for-you AI automation engagement look like?"
- "How long does setup take?"
- "What's included in the 90-day DFY engine?"
- "Do you really run your own outbound on the same stack?"
- "What if we already have a BDR or outbound tool?"
- "Is this for MSPs under 10 employees?"

### Link structure
- Primary CTAs link to the Cal.com fit call
- Internal link to tryplinko (for MSPs not ready to commit) — helps cross-navigation, strengthens tryplinko's SEO too
- External link to one authoritative source on Claude Cowork (Anthropic's product page) — outbound authority signal
- No affiliate links, no tracking pixels from non-Plinko domains
